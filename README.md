One-line famous last words from a phone at 1% battery: having seen every 3 a.m. search its owner ever made, it calls dying at 1% not the tragedy, but the mercy.

The program (`main.ts`) writes that line to `/output/entry.txt`. The line itself is in `line.txt`.

## Run it

```sh
node main.ts
```
